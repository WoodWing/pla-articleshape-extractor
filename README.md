# ⚠️ This repository is discontinued

Development has been discontinued in this public repository. The two tools formerly contained here have been moved to separate private repositories to improve release management.

Releases are still actively maintained and are available at the following download locations:

* The `Article Shape Extractor` tool, that used to reside in the `ArticleShapeExtractor` folder of this repository, has been moved to [this](https://woodwing.github.io/aila-indesign-plugin/) public download page. The tool has been renamed into `AILA InDesign Plugin`.

* The `Article Shape Uploader` tool, that used to reside in the `ArticleShapeUploader` folder of this repository, has been moved to [this](https://woodwing.github.io/aila-article-shape-uploader/) public download page. The tool has been renamed into `AILA Article Shape Uploader`.

An overview of the AILA components can be found [here](https://woodwing.github.io/aila-package/).
